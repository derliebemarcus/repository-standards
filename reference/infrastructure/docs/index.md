# Infrastructure documentation

Document complete bootstrap from an empty environment, required accounts and permissions, dependencies, directories, configuration, secrets handling, deployment topology, and safe local validation equivalents.

Operations documentation must cover routine procedures, monitoring, alerting, troubleshooting, backup, restore, rollback, and disaster recovery.

Changes to pipelines, deployment code, infrastructure definitions, configuration, or security boundaries normally require updates across architecture, reference, and operations documentation rather than a single isolated file.
