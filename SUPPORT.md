# Support

Repository Standards is maintained as a versioned public standards distribution rather than a hosted support service.

For questions or problems with the Public Core, open the appropriate GitHub Issue:

- **Bug Report** for a defect or contradiction;
- **Standard Change Proposal** for a proposed contract change;
- **Documentation Proposal** for missing or unclear public guidance.

Before filing an issue, identify the Repository Standards release and the specific pinned contract versions involved. Do not include credentials, private infrastructure details, or other sensitive information.

GitHub pull requests are not accepted. Accepted changes are implemented and qualified in the canonical Forgejo repository and appear on GitHub only after a later deterministic Public Core republication.
